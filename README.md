# ITCONNECT AI Service Showcase (수강생 전용 키노트 덱)

> **"우리는 AI를 가르치기 전에, 직접 만들어 씁니다."**  
> 불필요한 발표자 UI를 전면 제거하고, 실제 사이트 캡처와 타이포그래피 중심으로 재설계된 **수강생 집중형 에디토리얼 프레젠테이션**

---

## 🎛️ 무선 포인터 / 프리젠터 조작 안내

강의 시 무선 프리젠터(포인터 기기) 또는 마우스만으로 모든 조작이 가능하도록 최적화되어 있습니다.

| 조작 방식 | 동작 |
| :--- | :--- |
| **마우스 좌클릭** | **다음 슬라이드로 이동** |
| **마우스 우클릭** | **이전 슬라이드로 이동** |
| **마우스 앞/뒤 사이드 버튼** | **다음 / 이전 슬라이드 이동** |
| **무선 포인터 `PageDown` / `→` / `Space` / `Enter`** | **다음 슬라이드로 이동** |
| **무선 포인터 `PageUp` / `←` / `Backspace`** | **이전 슬라이드로 이동** |
| **키보드 `B` 또는 `.`** | **화면 가리기 (Blackout)** — 청중의 시선을 강사에게 집중시킬 때 사용 |
| **키보드 `F`** | **전체화면 (Fullscreen) 토글** |

## 🎨 디자인 재설계 핵심 변경점

1. **AI 생성물 특유의 정형화된 스타일 탈피**:
   - 일괄적인 사이버 다크/네온 그라디언트/글래스모피즘/이모지를 전면 폐기했습니다.
   - 서비스 도메인별 아이덴티티에 맞춘 **전용 컬러 테마**(크림 에디토리얼, 딥 포레스트 그린, 일렉트릭 블루, 어스 샌드 등)를 슬라이드마다 큐레이션했습니다.
   - **프리텐다드(Pretendard Variable) 볼드 국문 타이포**와 **인스트루먼트 세리프(Instrument Serif)**의 하이엔드 대비를 적용했습니다.
2. **슬라이더 레볼루션(Slider Revolution)급 전환 연출**:
   - 2중 컬러 슬롯 커튼 컷 전환(`clip-path: inset`) 애니메이션.
   - 텍스트 라인별 마스크 업 리빌(`overflow: hidden` + 회전 페이드).
   - 실제 사이트 브라우저 프레임 패럴랙스 플로팅.
3. **가짜 지표 및 허위 데이터 완전 제거**:
   - 임의로 지어낸 만족도/절감액 수치를 삭제하고, 각 서비스의 **실제 운영 사이트 본문 및 구축 사례 팩트**를 기반으로 작성했습니다.
4. **수강생을 위한 무대 정돈**:
   - 강사용 발표자 노트 드로어, 자동재생 타이머, 설정 모달 등 수강생 화면에 방해가 되는 요소를 모두 제거하고, 상단 로고와 하단 미니멀 프로그레스 카운터만 유지했습니다.

## 📑 14개 실전 서비스 구성

1. **[COVER]** 우리는 AI를 가르치기 전에, 직접 만들어 씁니다.
2. **Startora** (`startora.net`) — AI Agent 기반 경영관리 플랫폼 (사내 지식베이스, 문서 생성, 회의록 요약)
3. **Axio** (`consulting.itconnect.dev`) — 가치 중심 AI 전환(AX) 컨설팅 코파일럿 (병목 업무 발굴, 산출물 자동 생성)
4. **BizPlan** (`itconnect.co.kr`) — 공고문과 회사 자료 기반 AI 사업계획서 작성 서비스
5. **HOMEPAGE.WORKS** (`homepage.works`) — AI 활용 외주 개발 & 3분 기능별 실시간 견적 산출기
6. **Content Studio** (`content.itconnect.dev`) — 1개 주제로 블로그·스레드·인스타·FB 4대 채널 동시 발행
7. **Landing Maker** (`landingmaker.biz`) — 대화형 기획 기반 12단계 AI 상세페이지 제작 스튜디오
8. **GrowthLab** (`keypaper.biz`) — YouTube 채널·영상·트렌드 데이터 수집 및 AI 성장 인사이트
9. **GEO Dashboard** (`geo.itconnect.dev`) — 생성형 AI 검색 엔진(ChatGPT, Perplexity 등) 브랜드 노출 측정 및 진단
10. **광고 관측실** (`ads.itconnect.dev`) — 여러 플랫폼에 집행되는 광고 소재 자동 수집 및 비교
11. **GovNotice** (`gov.itconnect.dev`) — 정부지원사업 공고 실시간 수집 및 우리 회사 맞춤 선별 알림
12. **AI Information** (`info.itconnect.dev`) — 최신 AI 소식·논문 수집 및 블로그 글 자동 생성
13. **B-CREATOR** (`b-creator.com`) — AI 바이브코딩 단계별 실습 및 결과물 포트폴리오 아카이빙 플랫폼
14. **내 링크** (`favorite.itconnect.dev`) — 사내 498개 AI 도구와 23개 운영 사이트 단축키(Cmd+K) 검색 대시보드
15. **ITCONNECT** (`itconnect.dev`) — AX 컨설팅과 사내 AI 자동화 교육 (140분→8분 단축, 연 400h+ 절감 사례)
